# Cloud Resource Topology & Cost Estimator (`cloud-resource-topology`)

An enterprise-grade cloud infrastructure architecture designer and real-time cost estimation workspace built with React, TypeScript, and Tailwind CSS.

## Features

- **Interactive Topology Canvas:** Deploy and manage cloud services across AWS, GCP, and Azure.
- **Dynamic Cost Calculator:** Real-time run rate aggregation and annual financial projections.
- **Service Component Catalog:** Pre-configured templates for VPC gateways, compute instances, RDS clusters, and load balancers.
- **Strict Type Safety:** Comprehensive TypeScript interfaces for resources, providers, and specs.

## Setup & Running

1. Clone repository & install dependencies:
   ```bash
   cd cloud-resource-topology
   npm install
   ```
